# 🛰️ 宇宙挖矿机器人 Cosmic Mining Rover (CMR)

> 把一台开源扫地机器人，改装成一台能在地外天体表面自主勘探、识别并采集资源的 AI 挖矿机器人。
> 配合西安电子科技大学（西电）三代半（SiC/GaN）抗辐射功率器件、不锈钢轻量化外壳，以及 SpaceX rideshare 发射通道，构建一条「地面原型 → 在轨/月面验证 → 商业航天服务」的可执行路线。

---

## 0. 先说真话（现实可行性体检）

把机器人送上天不是"副业玩具"，而是**商业航天级别**的工程。先把账算清楚，再决定怎么玩：

| 项目 | 真实数字（2026） | 来源 |
|---|---|---|
| 最低发射门槛 | **$350,000 起**，含 50kg 到太阳同步轨道（SSO） | SpaceX Rideshare |
| 超出重量单价 | **$7,000 / kg** | SpaceX Rideshare 2026 |
| 发射节奏 | Transporter 任务约每 4 个月一班，SSO 525km / 97.5° | SpaceX |
| 载荷板配置 | 1/4 板 50kg / 1/2 板 100kg / 整板 200kg / XL 300kg | SpaceX |
| 西电抗辐射器件 | 抗辐射 SiC 功率器件已随**天舟六号**入空间站、在 LEO 卫星验证 | 西电芜湖研究院 |
| 开源底座成本 | ROS 2 扫地机器人整机硬件可压到**千元级** | 开源社区 |

**结论**：对个人/小团队而言，**真正的轨道发射（35 万美元起）不是"副业"能负担的**。但——
> 你真正能卖、能立刻开工的，是这套**自主勘探+AI 识别+在轨算力**的技术栈，以及它的**数字孪生与仿真 IP**。发射是这条技术链成熟后的"毕业典礼"，不是起点。

所以本项目采用**三段式路线**：先造能在地面跑的真原型 + 高保真仿真（现在就能做、现在就能变现），再找高校载荷竞赛/商业航天基金/科研客户做在轨验证，最后才是自己发射。

## 1. 概念：扫地机器人 → 宇宙挖矿机器人

扫地机器人和行星探测车（rover）在底层**高度同构**：

| 扫地机器人能力 | 对应挖矿机器人能力 |
|---|---|
| 差速底盘 + 轮编码器里程计 | 月/小行星表面移动与定位 |
| 2D LiDAR / ToF / 视觉 SLAM | 地表障碍规避、地形建图 |
| ROS 2 导航栈（Nav2）+ 全覆盖路径规划 | 矿产区域覆盖勘探 |
| 离心风机 + 尘盒（吸尘） | 替换为**钻取/研磨/采集工具头** |
| Raspberry Pi 主控 + Arduino 底层 | 替换为**抗辐射计算 + 电源模组** |
| 回充基站 | 替换为**太阳能/同位素电池 + 数据中继** |

**改装三板斧**：
1. 拆掉吸尘系统，装上轻量化**钻探/抓取工具头** + 样品仓。
2. 外壳换成**316L 不锈钢 / 钛合金**轻量化结构（抗温差、抗微流星、可焊接）。
3. 主控与电源换成**西电抗辐射 SiC 功率器件 + 抗辐射计算 SoC**，并用导热不锈钢骨架做散热/辐射屏蔽。

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                   Cosmic Mining Rover (CMR)                  │
├─────────────────────────────────────────────────────────────┤
│  感知层 (Sensing)                                            │
│   · 多光谱/高光谱相机  (AION 启发的 39 类模态统一表征)        │
│   · 2D LiDAR / ToF / IMU  (来自扫地机器人底座)               │
│   · 钻探振动谱 + 样品近红外 (ASTERIS 风格去噪)               │
├─────────────────────────────────────────────────────────────┤
│  AI 决策层 (Autonomy Stack)  —— 本项目的核心 IP              │
│   · 矿石源检测  ← CIANNA (YOLO 风格星系/源探测器)            │
│   · 多模态理解  ← AION 全模态基础模型 (天体识别/分类)         │
│   · 图像去噪    ← ASTERIS_THU (JWST 验证, +1 星等探测极限)    │
│   · 任务看板/预测 ← AstroIntel (NASA 数据/随机森林预测)      │
│   · 自主导航    ← Nav2 + 全覆盖勘探 (来自扫地机器人)          │
├─────────────────────────────────────────────────────────────┤
│  执行层 (Actuation)                                          │
│   · 差速底盘 (保留)   · 钻探/研磨工具头 (新增)               │
│   · 样品仓 (新增)     · 太阳能阵/电池 (替换回充基站)          │
├─────────────────────────────────────────────────────────────┤
│  抗辐射算力与电源 (Rad-Hard Core)  —— 西电三代半             │
│   · 抗辐射 SiC MOSFET 功率级 (西电芜湖研究院, 已在轨验证)     │
│   · 抗辐射计算 SoC (Xilinx Zynq UltraScale+ / Microchip)     │
│   · 不锈钢导热骨架兼具散热与部分粒子屏蔽                      │
└─────────────────────────────────────────────────────────────┘
```

### 开源天文 AI 工具如何接入
| 工具 | 在本项目中的角色 | 接入方式 |

## 4. AI 决策闭环（已做成可运行仿真）

`simulation/rover_sim.py` 是一个**不依赖任何付费服务、纯本地可跑**的高保真仿真，演示 CMR 的核心闭环：

```
勘探(explore) → 多光谱感知(sense) → ASTERIS风格去噪(denoise)
   → CIANNA风格矿石源检测(detect) → 接近(approach) → 钻采(mine)
   → 样品入库 → 中继回传(relay) → 续航管理 → 返回勘探
```

它输出：轨迹地图（SVG）、遥测日志（CSV）、每步决策摘要。**这就是你可以立刻交付、演示、甚至拿去参赛/卖给科研客户的"技术内核"。**

在火星车仿真逻辑之上，本仓库已扩展两大子系统（详见 `docs/system_overview.md`）：

- **① 集尘盒视觉识别 → 区块链售卖**（`simulation/dustbox_vision.py`）：集尘盒满时由机载摄像头成像（生成真实 PNG 快照）→ 最近质心分类器识别材质 → 每批铸造为可售区块链资产（`ledger.json` 中 `asset`/`sale` 区块），并给出市场估价(¥)。
- **② Starlink 星链通讯**（`simulation/starlink_comm.py`）：扫地机器人改装 CMR 通过 Musk 的 Starlink LEO 星座通讯，模拟过顶窗口、时延、带宽与离线缓存队列（`store-and-forward`）。

三个世界档：`generic`(类月) / `mars`(火星，含尘暴) / `depot`(地球·月球基地集尘售卖主舞台)。

## 5. 路线图（三阶段）

**阶段 A — 地面原型 + 仿真（0–6 个月，现在开始，< 2 万元）**
- clone OOMWOO，Gazebo 里把吸尘替换为勘探/采矿行为
- 跑通 `rover_sim.py`，沉淀 AI 决策栈（去噪+源检测+导航）
- 3D 打印不锈钢/PLA 外壳原型，装测试工具头
- **变现点**：仿真软件授权、教育套件、技术咨询

**阶段 B — 抗辐射化 + 立方星/载荷验证（6–18 个月）**
- 引入西电抗辐射 SiC 功率器件 + 抗辐射 SoC，做电源/算力板
- 参加高校/商业航天载荷竞赛（如 立方星、空间科学载荷），争取发射名额与赞助
- **变现点**：科研载荷设计服务、在轨验证数据产品

**阶段 C — 专属发射（18 个月+，需融资/客户预付款）**
- 通过 SpaceX rideshare（≥$350k / 50kg）或国内商业航天（星河动力/天兵等）发射
- 目标天体：近地小行星（采样返回难度高，先做绕飞+表层勘探）或月球南极（水冰/稀土）
- **变现点**：稀缺地外样品、在轨算力租赁、科研数据订阅

## 6. 现在就开始（你的第一步）

```bash
# 1) 跑通 AI 挖矿机器人仿真（纯本地，仅需 numpy）
cd simulation
pip install -r requirements.txt
python rover_sim.py --world depot --steps 500 --out map_depot.svg   # 集尘盒售卖主舞台
python rover_sim.py --world mars  --steps 600 --out map_mars.svg   # 火星采矿(含尘暴)
python rover_sim.py --world generic --steps 400                    # 类月默认

# 2) 看输出
#    - map_*.svg        轨迹与矿脉地图（机器人星链在线时变绿）
#    - telemetry.csv    每步遥测（含 dust_box / comms / lots / sales）
#    - summary.txt      任务总结（含集尘盒识别/星链/区块链统计）
#    - ledger.json      区块链全量哈希链
#    - snaps/lot_*.png  集尘盒内容物摄像快照（真实 PNG，可肉眼查看）

# 3) 把"吸尘"换成"采矿"——clone 开源底座
git clone https://github.com/<OOMWOO>/OOMWOO   # 见 docs 选型
```

## 7. 风险与诚实清单

- ❗ 发射成本（$350k 起）远超个人"副业"预算 → 用阶段 A/B 的技术产品先变现再发射。
- ⚠️ 西电目前公开的是**抗辐射 SiC 功率器件**，不是完整抗辐射主板 → 需自研电源/算力板并搭配商用抗辐射 SoC。
- ⚠️ 真实地外采矿涉及采样返回、能源、通信、法规（外空条约）→ 阶段 C 前需法律与工程尽调。
- ✅ 阶段 A 的仿真 + 原型是**真实可交付资产**，不依赖发射也能产生价值。
