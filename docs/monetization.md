# 变现路径：把"宇宙挖矿机器人"变成能赚钱的资产 / Monetization: Turning the "Cosmic Mining Robot" into a Money-Making Asset

> 语言说明 / Language note：本文中英双语，先中文后英文。 / This document is bilingual: Chinese first, then English.

诚实前提：在真正发射前，可变现的是**技术栈、仿真 IP 与数据产品**，不是矿石。以下是可立即启动的变现点。

Honest premise: before any real launch, what can be monetized is the **tech stack, simulation IP and data products**, not ore. Below are monetization points that can start immediately.

---

## ① 仿真软件 / 数字孪生授权（现在就能卖） / ① Simulation Software / Digital-Twin Licensing (Sellable Now)
- 把 `simulation/` 封装成 SaaS / 授权库：**行星表面自主勘探仿真器**。
  Package `simulation/` as SaaS / a licensed library: a **planetary-surface autonomous exploration simulator**.
- 客户：航天院校教学、立方星团队任务规划、机器人公司测试导航算法。
  Customers: aerospace university teaching, CubeSat team mission planning, robotics companies testing navigation algorithms.
- 形态：Web 版（Three.js + 后端）+ 本地 SDK。定价：教育免费 / 科研 $99–$999/年。
  Form: web version (Three.js + backend) + local SDK. Pricing: free for education / $99–$999 per year for research.

## ② 教育套件（硬件 + 课程） / ② Education Kits (Hardware + Courses)
- 基于 OOMWOO 开源底座，出"**勘探机器人教学套件**"：3D 打印件 + 主控 + 课程（导航/AI/遥感）。
  Based on the OOMWOO open-source base, offer an "**exploration robot teaching kit**": 3D-printed parts + main controller + courses (navigation / AI / remote sensing).
- 渠道：青少年航天科创、高校实训、科普机构。毛利高、起量快。
  Channels: youth aerospace STEM programmes, university practical training, science-outreach organizations. High margin, fast ramp-up.

## ③ 科研服务：在轨自主探测 AI 定制 / ③ Research Services: Custom In-Orbit Autonomous Detection AI
- 为高校/院所的卫星、巡视器提供**自主导航 + 目标识别**算法交付（移植 AION/ASTERIS/CIANNA 思路）。
  Deliver **autonomous navigation + target recognition** algorithms for university/institute satellites and rovers (porting AION/ASTERIS/CIANNA ideas).
- 结算：课题分包、横向项目，单笔 5–50 万人民币量级。
  Billing: research subcontracts and industry-funded projects, on the order of 50k–500k yuan each.

## ④ 数据标注 / 训练数据 / ④ Data Labelling / Training Data
- 用仿真批量生成**带标签的"行星表面-光谱-矿藏"数据集**，供天文/地质 AI 训练。
  Use the simulation to batch-generate **labelled "planetary surface – spectrum – deposit" datasets** for astronomy/geology AI training.
- 结合 AION（2 亿天体、39 类模态）做数据增强与基准。卖数据集 / 标注服务。
  Combine with AION (200 million objects, 39 modalities) for data augmentation and benchmarks. Sell datasets / labelling services.

## ⑤ 在轨算力 / 数据订阅（发射后） / ⑤ In-Orbit Compute / Data Subscriptions (After Launch)
- 真实在轨后：出售**稀缺地外样品光谱数据**订阅、在轨算力租赁（边缘推理）、科研合作。
  Once actually in orbit: sell subscriptions to **rare extraterrestrial sample spectral data**, in-orbit compute rental (edge inference), and research collaborations.
- 月球/小行星水冰与稀土数据是长期稀缺资产。
  Lunar/asteroid water-ice and rare-earth data are long-term scarce assets.

## ⑥ 参赛与资助（现金/发射名额） / ⑥ Competitions and Funding (Cash / Launch Slots)
- 商业航天创新创业大赛、立方星载荷征集——奖金 + 免费发射名额，本质是"低成本拿发射"。
  Commercial-space innovation and entrepreneurship competitions, CubeSat payload calls — prize money + free launch slots, essentially "getting a launch at low cost".

   **Immediately**: polish the simulation + design the education kit + build influence through open source.

   **3–6 months**: take on research algorithm outsourcing + dataset products.

   **1 year+**: use revenue/funding for radiation hardening and a rideshare launch, moving into in-orbit data monetization.
